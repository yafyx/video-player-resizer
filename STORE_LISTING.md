### Detailed description

Resize a video player on any web page without wrestling with the site's layout.
Click the Video Player Resizer icon, enable the current site, and drag a corner
or edge to get the size you want. Use the control deck for scale presets,
aspect-ratio lock, overflow, and remembered size. If automatic detection picks
the wrong box, Select element lets you point at the exact player or wrapper.

The extension is off until you enable a site. Your choices stay in Chrome
extension storage; Video Player Resizer has no account, analytics, ads, or
external service.

## Permission and data disclosures

- **`storage`:** stores settings, remembered dimensions, and an optional manual target path.
- **Content script on `<all_urls>`:** needed to inspect and resize video players on any page. The feature is inactive until the user enables that site; processing is local to the page.
- **No host permission block:** the static content-script match is the narrowest way this implementation can detect players before the user opens the controls.
- **Data handling:** the extension handles page structure, player geometry, and a site key locally. It does not transmit page data, sell data, show ads, or use analytics. The Limited Use and privacy-policy statements should match [PRIVACY.md](PRIVACY.md).

### Privacy practices tab

Use the dashboard's current labels to disclose that the extension handles
website content (the page structure and player geometry) and browsing activity
(the current site's hostname) locally for the resizing feature. Select that the
data is not sold or transferred to third parties, and certify that the data is
not used for advertising, creditworthiness, or unrelated purposes. Chrome's
policy requires local-only handling to be disclosed too; do not select "no data"
simply because nothing leaves the device.

## Test instructions for review

1. Open a normal HTTPS page containing an HTML5 video.
2. Click the Video Player Resizer toolbar icon.
3. Choose **Enable here**.
4. Hover the video and drag a corner or edge; verify the player changes size.
5. Open the control deck to try a preset, aspect-ratio lock, and **Restore**.
6. Choose **Select element**, click a player or wrapper, and reload the page to verify the target is restored.
7. Disable the site and confirm the overlay disappears and the page returns to its original layout.

The extension does not require an account, test credentials, or a backend.
